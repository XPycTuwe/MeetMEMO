# MeetMemo

Локальная стенография встреч для Windows 11. Приложение живёт в трее: по горячей клавише
вы выбираете окно встречи, оно раздельно захватывает микрофон и звук этого приложения,
**ведёт стенограмму на русском в реальном времени** и складывает всё в папку встречи.
Готовый пакет можно одним архивом отдать Claude и получить мемо.

Звук и стенограмма никуда не уходят: распознавание работает на вашем компьютере.
Единственная передача данных — ZIP-архив, который вы загружаете в Claude сами.

## Что уже работает

- Захват звука выбранного приложения (WASAPI process loopback по дереву процессов)
  с автоматическим переходом на общий системный звук, если изоляция недоступна
- Захват микрофона; запись обеих дорожек в WAV — отключаемая настройка
- Живая стенограмма на русском: sherpa-onnx + GigaAM v2, нарезка речи через Silero VAD,
  дозапись `transcript.jsonl` по ходу встречи
- Финальный уточняющий проход по сохранённому аудио (Whisper.net) — даёт пунктуацию и заглавные
- Снимки целевого окна (вручную и автоматически по интервалу + изменению кадра),
  снимок рабочего стола только вручную
- Плавающая панель поверх окна встречи: не забирает фокус и не попадает в собственные снимки
- Кнопки записи прямо в заголовке окна отмеченного приложения: свёрнуты до маленького
  значка, разворачиваются при наведении курсора
- Глобальные горячие клавиши, работающие поверх Teams и браузера
- Восстановление пакета после аварийного завершения приложения
- Сборка ZIP с предварительным показом состава
- Claude Skill `meeting-memo` для превращения пакета в мемо

## Значок приложения

Иконки собираются из `ico.png` в корне проекта:

```powershell
pwsh -File tools/make-icons.ps1
```

Получаются `app.ico` (7 размеров, от 16 до 256 — для панели задач, проводника
и переключателя окон) и три значка для области уведомлений: обычный, с красной точкой
во время записи и с жёлтой на паузе. Точка занимает чуть больше трети значка —
различима даже в 16 пикселях, но логотип не закрывает.

После замены `ico.png` запустите скрипт и пересоберите приложение.

## Требования

- Windows 11 x64 (нужен process loopback; на Windows 10 2004+ основной контур тоже работает)
- .NET 8 SDK для сборки, .NET 8 Desktop Runtime для запуска
- ~1 ГБ на диске под модели распознавания

## Запуск

Самый простой способ — двойной щелчок по **`MeetMemo.bat`** в корне проекта.
Он находит собранное приложение (сначала в `dist\`, затем в `bin\`) и запускает его.
Окно не появится: MeetMemo живёт в области уведомлений, значок справа внизу.

Собрать готовый к раздаче дистрибутив:

```bash
publish.cmd
```

Получится папка `dist\MeetMemo\` с `MeetMemo.exe` и ярлыком `dist\MeetMemo.lnk`.
По умолчанию сборка автономная — .NET внутри, устанавливать ничего не нужно (~210 МБ).
Вариант полегче, если .NET 8 Desktop Runtime уже стоит:

```bash
publish.cmd -Portable
```

## Сборка из исходников

```bash
dotnet build MeetMemo.sln -c Release
```

```bash
dotnet run --project src/MeetMemo.App -c Release
```

Модели распознавания приложение предложит скачать при первом запуске (~230 МБ).
Проверить их можно через меню значка в трее → «Проверить модели распознавания».

Тесты:

```bash
dotnet test tests/MeetMemo.Tests
```

Проверка распознавания на готовом WAV-файле:

```bash
dotnet run --project tools/AsrSmoke -- путь/к/файлу.wav
```

Сквозная проверка контура (запись → стенограмма → пакет → ZIP) без интерфейса:

```bash
dotnet run --project tools/E2ESmoke -c Release -- 25
```

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `Ctrl+Alt+M` | Начать / завершить встречу |
| `Ctrl+Alt+P` | Пауза / продолжить |
| `Ctrl+Alt+S` | Снимок целевого окна |
| `Ctrl+Alt+D` | Снимок рабочего стола |
| `Ctrl+Alt+I` | Маркер «Важно» со снимком |

Комбинации сознательно выбраны обычными: клавиша Copilot есть далеко не на всех клавиатурах.
Если комбинация занята другим приложением, MeetMemo сообщает об этом явно, а не молчит.

## Запись всего звука системы

Если встреча идёт в браузере, сразу в нескольких приложениях или искать нужное окно
некогда — в меню значка есть пункт **«Записать весь звук системы»**. Он пишет всё, что
звучит на компьютере, плюс микрофон, без привязки к окну.

Плата за удобство — отсутствие изоляции: в дорожку попадёт и музыка, и звук уведомлений.

Окна-цели у такой записи нет, поэтому вместо значка в заголовке появляется плавающая
панель поверх экрана: таймер, кнопка снимка всего рабочего стола, «Пауза», «Важно»
и «Стоп». Её можно перетащить мышью — положение запоминается. В снимки она не попадает.
Управление доступно и из меню значка в трее, и горячими клавишами.

## Отмеченные приложения

В окне выбора источника у каждого приложения есть колонка «Вести». Отметьте те, в которых
проходят встречи (Teams, TrueConf, Zoom, браузер) — и в заголовках их окон появится
маленький значок MeetMemo. Наведите на него курсор: развернётся управление записью —
«Записать», а во время встречи ещё «Пауза», «Снимок» и «Важно».

Значок сам показывает состояние: серый — готов, красный — идёт запись, жёлтый — пауза.
Отметка действует на приложение целиком и сохраняется между запусками.

Во время записи слева от значка появляется кнопка снимка — нажимается сразу, разворачивать
панель не нужно. В самой панели есть галочка «Автоснимки экрана»: её можно снять посреди
встречи, когда на экране появляется лишнее, и вернуть обратно. Выбор запоминается.

## Пакет встречи

```
2026-07-31_1430_Совещание/
├── session.json          параметры встречи
├── timeline.jsonl        события с таймкодами
├── transcript.jsonl      стенограмма построчно
├── transcript.md         читаемая версия
├── glossary.md           словарь терминов (заполняете вы)
├── audio/                дорожки, если включено сохранение
├── screenshots/          снимки + index.json
├── diagnostics/          журналы
└── output/               сюда кладёте результаты Skill из Claude
```

Все форматы открытые: JSON, JSONL, Markdown, WAV, PNG. Пакет читается без MeetMemo.

## Как получить мемо

1. В карточке завершения нажмите «Собрать ZIP для Claude».
2. Загрузите архив в Claude.
3. Попросите подготовить мемо — обработку выполнит Skill `meeting-memo` (папка `skill/`).

Skill получит стенограмму, шкалу событий и снимки и соберёт `memo.md`,
`transcript_clean.md` и `actions.json` с таймкодами и пометками неуверенности.

## Известные ограничения

- **Стенограмма идёт без пунктуации и заглавных букв.** Так работает GigaAM — лучшая
  открытая русская модель по точности слов. Читаемый текст даёт финальный проход Whisper
  и мемо, собранное в Claude.
- **Изоляция звука работает по процессу, а не по окну.** У браузеров в дорожку может попасть
  звук другой вкладки того же процесса — приложение предупреждает об этом при выборе браузера.
- **Исключение панели из снимков — best effort.** `WDA_EXCLUDEFROMCAPTURE` не является DRM
  и не гарантирует невидимость во всех способах записи экрана.
- **Свёрнутое окно не отдаёт кадры.** Автоснимки на это время приостанавливаются,
  запись звука продолжается.
- Финальный проход требует включённого сохранения аудио — пересчитывать иначе нечего.

## Правовое напоминание

Предупреждайте участников о записи и соблюдайте правила вашей организации
и применимое законодательство. Во время записи всегда видны красный значок в трее
и панель с таймером — скрытой записи в продукте нет.
